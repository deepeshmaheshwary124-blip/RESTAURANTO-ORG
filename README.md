# Dua Restaurant Maripur

Production-oriented React/Vite restaurant website.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

The imagery uses editorial/stock food and restaurant photography because verified Dua Restaurant photography was not available in the supplied files. The site deliberately does not present those images as authentic restaurant photographs.

Replace the image URLs in `src/App.tsx` with approved restaurant images whenever available.
